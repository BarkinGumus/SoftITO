# Power BI – Ders Ödevi: Satış Analizi (2016–2019)

2016–2019 satış verisi üzerinde ilişkili tablolarla basit bir satış raporu.

## Veri modeli
- **Fact tablosu:** `2016-2019` (TotalPrice, TotalCost)
- **Boyutlar:** `country2` (ülke), `products2` (ürün)

## Rapor
- Ülkelere göre toplam satış tutarı (line chart)
- Ürünlere göre toplam maliyet (line chart)
